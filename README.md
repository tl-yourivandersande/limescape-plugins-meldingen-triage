# Limescape plugins — Meldingen triage

Public plugin bundle for the **Meldingen triage** team.

- Bundle key: `meldingen-triage` (confirm with a Limescape administrator before registration).
- Node code prefix: `meldingen_triage_`.
- Node types live under `src/node-types/<code>/`.
- Create a release by tagging `main` with `vX.Y.Z`; the release workflow builds the bundle and publishes its activation checksum.
- Limescape administrators register the bundle source and activate releases for the team.

This repository is public. Do not commit customer data, real addresses, identifiers, credentials, or secrets. Configuration that varies between environments belongs in node form fields, not plugin code.

The repository's licence must be decided before distributing a release.
